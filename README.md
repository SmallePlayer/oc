# oc

Небольшая C++ библиотека-обёртка над BSD-сокетами для работы по сети (TCP и UDP).

## Возможности

- Создание сокетов (`TCP` / `UDP`)
- Настройка сервера и клиента
- Отправка и приём `int`, `char*`, произвольных структур и байтов
- Задержки (секунды, миллисекунды, микросекунды)

## Сборка

```sh
cmake -B build
cmake --build build
```

## Структура

- `core/` — сама библиотека (`net.hpp`, `net.cpp`)
- `test/` — простые тесты клиента и сервера (UDP)
- `example/` — пример передачи структуры `Robot` по TCP
